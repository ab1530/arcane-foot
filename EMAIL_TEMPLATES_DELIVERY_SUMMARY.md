## Technical Requirements

### Email Service Provider
**Recommended:** SendGrid, Mailgun, or AWS SES

**Requirements:**
- HTML email support
- Personalization variables (Handlebars/Liquid)
- A/B testing capabilities
- UTM tracking
- Webhook integration with Stripe

### Stripe Configuration

**Discount Codes:**
1. **GOLDUPGRADE30**
   - Type: Coupon
   - Discount: 30% off
   - Duration: Once (first month)
   - Expiry: 7 days from launch
   - Max redemptions: 1,000

2. **LOYALTY Pricing**
   - Type: Special price
   - Amount: €19.99 (first month)
   - Then: €49.99/month
   - Applies to: BASIC → GOLD upgrades

### Personalization Variables

**All Emails:**
- `{{user.name}}` - User's first name
- `{{user.email}}` - User's email
- `{{user.tier}}` - Current tier (FREE/BASIC/GOLD/PRO/ENTERPRISE)
- `{{user.createdAt}}` - Account creation date

**Segment-Specific:**
- FREE: `{{campaign.discountCode}}`, `{{campaign.endDate}}`
- BASIC: `{{user.subscriptionEnd}}`, `{{user.monthlyPrice}}`
- GOLD+: `{{user.aiUsageCount}}`, `{{user.memberSince}}`

### Tracking & Analytics

**UTM Parameters:**
```
utm_source=email
utm_medium=campaign
utm_campaign=rbac_rollout
utm_content=[free_users_30off | basic_users_loyalty | gold_users_retention]
```

**Event Tracking:**
- Email sent
- Email opened
- Link clicked
- CTA clicked
- Discount code applied
- Subscription upgraded
- Unsubscribed
