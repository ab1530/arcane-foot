# Sample Voice Report Prompts

Use these sample prompts to test the Voice-to-Report system. You can either:
1. Read these aloud and record them as audio files
2. Use them directly with the test-transcription endpoint
3. Modify them for your own testing

## English Samples

### Sample 1: Complete Defender Report

```
This is a scouting report for John Doe, center back, number 5, playing for Real Madrid against Barcelona in La Liga at Santiago Bernabéu on February 15th 2024.

Technical rating: 8 out of 10.
Physical rating: 9 out of 10.
Tactical rating: 7 out of 10.
Mental rating: 8 out of 10.
Overall rating: 8 out of 10.

Strengths: Excellent positioning, strong in the air, good passing range. He reads the game very well and rarely loses a header. His long passes to the wingers are consistently accurate.

Weaknesses: Can be slow to turn when facing quick attackers. Sometimes caught out of position on counter-attacks. Needs to work on his one-on-one defending against pacy forwards.

Key moments: Made a crucial goal-line block in the 67th minute that saved a certain goal. Won every aerial duel in the second half, totaling 12 out of 12 headers won. His pass in the 82nd minute started the counter-attack that led to our goal.

Overall impression: Top-quality defender with Champions League potential. He dominated the box and showed great leadership throughout the match. Would fit perfectly in our defensive system.

He played the full 90 minutes and never showed signs of fatigue.

Recommendation: Sign.
```

## Tips for Recording

When recording these samples as audio:

1. **Speak Clearly**: Enunciate each word, especially numbers and names
2. **Moderate Pace**: Not too fast, not too slow - conversational speed
3. **Natural Tone**: Sound professional but natural
4. **Pause Between Sections**: Brief pause after ratings, strengths, etc.
5. **Consistent Volume**: Maintain steady volume throughout
6. **Quiet Environment**: Record in a quiet room with minimal background noise
7. **Good Microphone**: Use a decent quality microphone if possible
8. **Multiple Takes**: Record 2-3 versions to test consistency

## Frontend Integration Example

```typescript
// Record audio in browser
const mediaRecorder = new MediaRecorder(stream);
const audioChunks = [];

mediaRecorder.ondataavailable = (event) => {
  audioChunks.push(event.data);
};

mediaRecorder.onstop = async () => {
  const audioBlob = new Blob(audioChunks, { type: 'audio/webm' });
  const formData = new FormData();
  formData.append('audio', audioBlob, 'report.webm');
  formData.append('language', 'en');

  const response = await fetch('/api/voice-to-report/process', {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${token}` },
    body: formData,
  });

  const result = await response.json();
  // Auto-fill form with result.extractedData
};
```
