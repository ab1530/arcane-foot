## 📊 State Flow Diagram

┌─────────┐
│  IDLE   │  Scout clicks "Start Recording"
└────┬────┘
     │
     ↓  Browser requests microphone permission
     │
┌────┴────────┐
│ RECORDING   │  Audio waveform animating, timer running
└────┬────────┘  Max 3 minutes
     │
     ↓  Scout clicks "Stop" (or auto-stop at 3 min)
     │
┌────┴────────┐
│  RECORDED   │  Audio saved as Blob, playback available
└────┬────────┘
     │
     ↓  Scout clicks "Process Recording"
     │
┌────┴─────────┐
│ PROCESSING   │  Uploading → Transcribing → Extracting
└────┬─────────┘  Shows progress messages
     │
     ↓  Processing complete
     │
┌────┴────────┐
│  COMPLETE   │  Shows transcription + extracted data
└────┬────────┘
     │
     ↓  Scout clicks "Apply to Form"
     │
┌────┴────────┐
│    FORM     │  All fields pre-filled
│  POPULATED  │  Scout reviews and submits
└─────────────┘

## 🔄 Data Flow Detail

┌─────────────┐
│  User Voice │
└──────┬──────┘
       │
       ↓
┌──────────────────────┐
│  Browser Audio Input │
│  (getUserMedia)      │
└──────┬───────────────┘
       │
       ↓
┌──────────────────────┐
│  MediaRecorder API   │
│  - Captures audio    │
│  - Creates chunks    │
└──────┬───────────────┘
       │
       ↓
┌──────────────────────┐
│  Audio Blob          │
│  (webm/ogg/mp4)      │
└──────┬───────────────┘
       │
       ↓
┌──────────────────────┐
│  FormData            │
│  - audio: Blob       │
│  - language: "en"    │
└──────┬───────────────┘
       │
       ↓
┌──────────────────────┐
│  HTTP POST Request   │
│  /api/voice-to-report│
└──────┬───────────────┘
       │
       ↓
┌──────────────────────────┐
│  Backend Processing      │
│  1. Save temp file       │
│  2. Send to Whisper API  │
│  3. Get transcription    │
│  4. Send to GPT-4 API    │
│  5. Parse JSON response  │
│  6. Calculate confidence │
│  7. Generate suggestions │
│  8. Delete temp file     │
└──────┬───────────────────┘
       │
       ↓
┌──────────────────────────┐
│  JSON Response           │
│  {                       │
│    transcription,        │
│    extractedData,        │
│    confidence,           │
│    suggestions           │
│  }                       │
└──────┬───────────────────┘
       │
       ↓
┌──────────────────────────┐
│  Frontend Updates        │
│  - Show transcription    │
│  - Show extracted fields │
│  - Show confidence       │
│  - Enable editing        │
└──────┬───────────────────┘
       │
       ↓
┌──────────────────────────┐
│  User Reviews & Edits    │
│  (if needed)             │
└──────┬───────────────────┘
       │
       ↓
┌──────────────────────────┐
│  Apply to Form           │
│  - Pre-fill all fields   │
│  - User submits          │
└──────────────────────────┘

## 🚀 Quick Start Flow

Developer:
1. Import component → 2. Add to JSX → 3. Handle onComplete

User:
1. Click voice button → 2. Record → 3. Process → 4. Apply

Backend:
1. Receive audio → 2. Transcribe → 3. Extract → 4. Return JSON

## ✅ Success Path

Scout opens form
     ↓
Clicks "Voice Report"
     ↓
Modal opens
     ↓
Clicks "Start Recording"
     ↓
Grants microphone permission
     ↓
Speaks for 1-2 minutes
     ↓
Clicks "Stop Recording"
     ↓
Reviews audio (optional play)
     ↓
Clicks "Process Recording"
     ↓
Waits 10-20 seconds
     ↓
Reviews transcription
     ↓
Reviews extracted data
     ↓
Edits if needed
     ↓
Clicks "Apply to Form"
     ↓
Form is pre-filled
     ↓
Scout submits report
     ↓
✅ Report saved in database

Time: ~2 minutes (vs 10-15 minutes manual)
Savings: 80-85% faster!
