# Arcane Fonts Directory

This directory should contain the **Ananston** font files for the Arcane brand.

## Required Font Files

Place the following font files in this directory:

1. **Ananston-Regular.woff2**
   - Weight: 400 (Regular)
   - Used for: Body text, subtitles

2. **Ananston-Medium.woff2**
   - Weight: 500 (Medium)
   - Used for: Subtitles, section headers

3. **AnanstonExpanded-Medium.woff2**
   - Weight: 500 (Medium)
   - Used for: Headlines, main titles

## Font Format

- **Format**: WOFF2 (recommended for web)
- **Fallback**: The app will use Inter font if Ananston files are not available

## Where to Get the Fonts

Contact Arcane GmbH or your brand manager to obtain the official Ananston font files.

## Installation

1. Place the .woff2 files in this directory (`/src/fonts/`)
2. The files are already configured in `/src/app/layout.tsx`
3. Restart the development server (`npm run dev`)
